# 2DCombat

Unity(C#)로 만든 2D 액션 전투 학습 프로젝트입니다.

## 프로젝트 성격

이 프로젝트는 Unity 교육 과정에서 강사의 지도에 따라 제작한 **학습용 프로젝트**입니다.
전체적인 코드 구조와 기능(무기 시스템, 몬스터 시스템 등)은 수업 커리큘럼을 따랐으며,
그 안에서 아래 부분은 직접 판단으로 정했습니다.

- **무기 디자인**: 원래 낫 형태로 진행된 걸, 심플하면서도 킹받는 막대기 무기로 변경
- **몬스터 배치 및 수량**: 난이도를 고려해 위치와 수를 범위 내에서 직접 조정
- **사운드**: 강사가 제공한 다운로드 후보군 중에서 직접 듣고 선택

## 개발 환경

- Unity 2022.3.14f1
- C#

## 실행 방법

1. Unity Hub에서 **Unity 2022.3.14f1** 을 설치합니다.
2. 이 저장소를 내려받아 Unity Hub의 **Add → Add project from disk** 로 폴더를 엽니다.
3. `Assets/Scenes/SampleScene.unity` 씬(빌드 설정에 등록된 씬)을 열고 ▶ Play 를 누릅니다.

## 조작키 (입력 설정 파일 기준)

| 동작 | 키 |
|---|---|
| 좌우 이동 | `A` / `D` 또는 `←` / `→` |
| 점프 | `Space` |
| 근접 공격 | `Left Ctrl` |
| 스킬 1 · 스킬 2 (핫바) | `Q` / `W` |
| 메뉴 열기·닫기 | `Esc` |

- 화면 아래 칸 3개는 **기본 공격 · 스킬 1(`Q`) · 스킬 2(`W`)** 입니다. 사용하면 그 칸에 쿨타임이 표시됩니다.
- 시작할 때 핫바에는 **대시(`Q`, 쿨타임 1초)와 방패(`W`, 5초 유지·쿨타임 5초)** 가 들어 있어 바로 쓸 수 있습니다.
- `Esc` 메뉴의 **스킬** 탭에서 스킬을 클릭하면 해금되고(빨간색 → 원래 색), 해금한 스킬은 아래 핫바 칸으로 끌어다 놓아 바꿔 낄 수 있습니다.
- 점프는 `Space`를 **짧게 누르면 낮게, 길게 누르면 높게** 뜁니다. (최대 높이는 `jumpPower`로 정해지고, 키를 일찍 떼면 상승이 `jumpCutMultiplier`(기본 0.5)만큼 줄어듭니다.)

## 구현된 기능 (코드 기준)

- **플레이어**: 이동·점프(`Rigidbody2D`), 대시(`DashSkill`), 방패 스킬(`ShieldSkill`). 스킬은 `BaseStrategy`를 상속한 `ScriptableObject`로 만들어 핫바에 끼워 쓰는 구조입니다.
- **근접 공격** (`PlayerMeleeAttack`): `CircleCastAll`로 범위 안의 `Idamageable` 대상을 찾아 피해를 줍니다.
- **체력·피격**: `EnemyHealth`(체력바, 피격 파티클, 피격음, Cinemachine Impulse 카메라 흔들림), 파괴 가능한 풀(`GrassHealth`).
- **UI**: 핫바, 스킬 슬롯·스킬 트리 보관함(드래그), 쿨타임 표시(DOTween), 일시정지 메뉴(`UIOptionView`, `Esc`로 열면 `Time.timeScale = 0`).
- **스킬 쿨타임** (`Hotbar.TryCast`): 스킬마다 `cooldown` 값(스킬 에셋에서 조절, 기본 1초)이 있고, 방패는 유지 시간보다 짧게 다시 쓸 수 없어 겹치지 않습니다. 일시정지 중에는 스킬이 나가지 않습니다.
- **스킬 트리 → 핫바 드래그**: 해금한 스킬만 핫바로 끌어다 놓을 수 있습니다.
- **스킬 트리 해금 규칙** (`UISkillSlot`): `shouldBeUnlocked`의 슬롯이 모두 해금돼 있어야 하고, `shouldBelocked`의 슬롯은 모두 잠겨 있어야 해금됩니다. 현재 씬 설정은 A → B, C → D 두 갈래이며, C·D는 A가 잠겨 있을 때만 해금됩니다 (갈래 선택).
- **입력**: Unity Input System 1.7.0 (`Control.inputactions`). 핫바 키(Q/W)는 기존 `Input.GetKeyDown` 방식이며, 프로젝트의 입력 처리 설정이 "Both"라서 함께 동작합니다.
- **사운드**: `SoundManager`(싱글톤)로 효과음 재생.
- **사용한 외부 에셋·패키지**: DOTween, Cinemachine 2.9.7, Universal RP 14.0.9, TextMesh Pro, Kenney 픽셀 플랫포머 타일 에셋(`Assets/Art/Download`).

## 수정 기록 (2026-11 점검)

Unity 2022.3.14f1에서 자동 플레이 테스트(60개 항목)를 만들어 돌리며 아래를 고쳤고, 고친 뒤 모두 통과를 확인했습니다.

- 스페이스를 누른 채 착지한 뒤 떼면 점프가 한 번 더 나가던 문제
- "길게 누르면 높이" 점프가 같은 프레임에 취소되어 항상 같은 높이였던 문제 (최대 높이는 그대로 유지)
- 적·풀을 칠 때마다 없는 소리 파일을 불러 경고가 뜨던 문제
- 씬을 다시 불러오면 대시가 오류를 내던 문제 (이벤트 구독 해제)
- 핫바·쿨타임 UI와 일시정지 메뉴가 씬에서 꺼진 채 저장되어 `Q`/`W`·`Esc`가 동작하지 않던 문제
- 쿨타임 표시가 처음부터 아이콘을 가리고, 세 칸 모두 기본 공격에만 반응하던 문제
- 스킬에 쿨타임이 없어 연타하면 대시가 연속으로 나가고 방패가 겹치던 문제
- 스킬 트리: 선행 조건 검사가 거꾸로 되어 있던 문제, 슬롯 C·D가 서로를 선행 조건으로 지정한 문제, 잠긴 스킬만 드래그되던 문제, 잠긴 스킬을 끌다 놓으면 다음 드래그가 엉뚱한 칸을 바꾸던 문제
- 빈 아이템을 표시할 때 생기던 오류(`UISlot.UpdateUI`)
- 에디터 전용 `using` 한 줄 때문에 빌드에서 오류가 날 수 있던 문제 (`Player.cs`)
