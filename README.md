## 프로젝트 성격

이 프로젝트는 Unity 교육 과정에서 강사의 지도에 따라 제작한 **학습용 프로젝트**입니다.
전체적인 코드 구조와 기능(무기 시스템, 몬스터 시스템 등)은 수업 커리큘럼을 따랐으며,
그 안에서 아래 부분은 직접 판단으로 정했습니다.

- **무기 디자인**: 원래 낫 형태로 진행된 걸, 심플하면서도 킹받는 막대기 무기로 변경
- **몬스터 배치 및 수량**: 난이도를 고려해 위치와 수를 범위 내에서 직접 조정
- **사운드**: 강사가 제공한 다운로드 후보군 중에서 직접 듣고 선택

## 개발 환경

- Unity 2022.3.14f1
- C#
